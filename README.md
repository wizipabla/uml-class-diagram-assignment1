# Online Bookstore & Delivery System - UML Class Diagram Assignment

## Project Overview
This repository contains the UML Class Diagram modelling assignment for the **Online Bookstore & Delivery System**. The project is developed as part of the object-oriented modeling coursework at Kigali Independent University (ULK)[span_1](start_span)[span_1](end_span)[span_2](start_span)[span_2](end_span).

## Business Idea & Scope
* **Business Idea:** A digital e-commerce platform that enables customers to explore a book catalog, manage a shopping cart, place orders, and track shipments[span_3](start_span)[span_3](end_span).
* **Project Scope (Included):** Customer registration, book catalog browsing, shopping cart item management, order processing, and shipment tracking[span_4](start_span)[span_4](end_span).
* **Project Scope (Excluded):** Secure third-party payment gateway API integrations, automated courier tracking webhooks, and machine learning recommendation engines[span_5](start_span)[span_5](end_span).

## Classes and Responsibilities Overview
The system is modeled using 5 core classes:
1. **Customer:** Manages user profiles, contact information, and delivery addresses[span_6](start_span)[span_6](end_span).
2. **Book:** Maintains book identification details, pricing, and stock levels[span_7](start_span)[span_7](end_span).
3. **ShoppingCart:** Temporarily stores selected books and calculates the total cost before checkout[span_8](start_span)[span_8](end_span).
4. **Order:** Handles the transition of cart items into a formal purchase record and tracks fulfillment status[span_9](start_span)[span_9](end_span).
5. **Shipment:** Monitors dispatch records, tracking numbers, and delivery dates[span_10](start_span)[span_10](end_span).
